# Calm Quest

An all-in-one mobile app that helps people with anxiety find daily calm through three integrated pillars: daily inspirations, therapeutic mini-games, and curated calming music/soundscapes.

## Tech Stack
- Frontend: Vite + React + TypeScript + Tailwind CSS
- PWA: vite-plugin-pwa
- Navigation: React Router
- Icons: Lucide React

## Project Structure
- `src/components/`: Reusable UI components
- `src/pages/`: Main application pages
- `src/layouts/`: Layout components
- `src/content/`: App content (JSON)
- `src/assets/`: Static assets
- `src/hooks/`: Custom React hooks
- `src/utils/`: Helper functions
- `src/services/`: External service integrations
